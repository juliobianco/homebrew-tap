# Homebrew tap

```
brew install --cask juliobianco/tap/claudy-usage
```

Casks: [Claudy Usage](https://github.com/juliobianco/claudy-usage-mac). The app is ad-hoc signed and not notarized; the cask removes the quarantine flag after install.

On a new release, bump `version` and `sha256` in `Casks/claudy-usage.rb` (the `.sha256` file is attached to each release).
